基于STMF103C8T6的水面垃圾清理机器人
基础包含 K230 
        TB6612 * 2
        AJ-SRP04M * 3
        MPU 6050
工程总体目的
设计并实现一台能在水面自主/远程识别、靠近并回收浮漂垃圾的水面清理机器人，具备避障、姿态补偿与任务状态管理能力，能将回收的垃圾集中输送存储。
核心功能目标

视觉识别：用 K230 模组做垃圾检测与目标定位（TRASH, x, y），为运动控制提供目标坐标。
自主导航与靠近：基于 STM32F103 的任务调度与 FSM（INIT → SEARCH → DETECT → APPROACH → COLLECT ↕ AVOID ↕ RETURN）完成巡航、目标逼近与避障。
回收作业：驱动回收滚筒与传送电机将目标物集中到存储区。
姿态与稳定性：用 MPU6050 + 互补滤波进行姿态估计，结合 PID 控制补偿航向/速度（舵效分配），提高靠近/回收精度。
环境感知与避障：3 路超声（前/左/右）用于近距避障与安全逼停。
通信与监控：USART 环形缓冲接收视觉模组数据，预留遥控/地面站/GPS 接口用于调试与远程监控。
实时调度：基于 SysTick 的多周期任务（10/20/50/100/200/500/1000ms）保证传感、控制、状态机和遥测定期执行。

成功判定（验收要点）

视觉模块能稳定识别目标并输出可靠坐标（误差和丢失率在可接受范围内）。
在无/弱风况下能可靠从搜索到收集完成一个目标（完整 FSM 流程成功执行）。
避障逻辑在 3 路超声触发下能及时保护平台，避免碰撞或翻覆。
回收机构（滚筒+传送）能将目标物稳定运送到存储区。
系统在预期电池供电下能工作达到设计续航（含电源保护与低电返航）。
