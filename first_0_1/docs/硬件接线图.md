# 水面垃圾清理机器人：扩展版硬件接线图

本图对应 STM32F103C8T6 的最终扩展版引脚方案。文中的“软件已适配”描述源码配置，不代表板级、整机或水上实测已经完成。

## 1. 系统连接总览

```text
                         ┌───────────── K230 ─────────────┐
                         │ RX ◄── PA9  USART1_TX          │
                         │ TX ──► PA10 USART1_RX          │
                         └──────────────┬─────────────────┘
                                        GND

┌──────── GPS ────────┐                 │
│ RX ◄── PA2 USART2_TX│                 │
│ TX ──► PA3 USART2_RX│           ┌─────▼─────┐
└──────────┬──────────┘           │ STM32F103 │
          GND                     │   C8T6    │
                                  └─────┬─────┘
                                        │ I2C1（重映射）
                              PB8/SCL ──┼── MPU6050 SCL / QMC5883L SCL
                              PB9/SDA ──┼── MPU6050 SDA / QMC5883L SDA
                                        │
                    ┌───────────────────┼───────────────────┐
                    │                   │                   │
              TB6612#1            TB6612#2          AJ-SRP04M ×3
             左右推进              滚筒/传送          前 / 左 / 右
```

所有模块、电机驱动和两路电源的 GND 必须相连。电机 VM 使用电池 A；控制逻辑电源使用稳定的 3.3 V / 5 V 转换电源。

## 3. 必须的 AFIO 重映射

以下配置必须在相关 GPIO、TIM2、I2C1 和超声波外设初始化之前执行：

```c
RCC_APB2PeriphClockCmd(RCC_APB2Periph_AFIO, ENABLE);

/* TIM2: CH1=PA0, CH2=PA1, CH3=PB10, CH4=PB11 */
GPIO_PinRemapConfig(GPIO_PartialRemap2_TIM2, ENABLE);

/* I2C1: SCL=PB8, SDA=PB9 */
GPIO_PinRemapConfig(GPIO_Remap_I2C1, ENABLE);

/* 关闭 JTAG，保留 PA13/PA14 的 SWD 调试 */
GPIO_PinRemapConfig(GPIO_Remap_SWJ_JTAGDisable, ENABLE);
```

`GPIO_Remap_SWJ_JTAGDisable` 只释放 JTAG 使用的 PB3、PB4、PA15；SWD 的 PA13、PA14 仍然可供 ST-Link 使用。

## 4. 外设接线

### 4.1 TB6612#1：左右推进

```text
STM32                         TB6612#1
PA0  (TIM2_CH1) ───────────► PWMA   左推进 PWM
PB12             ───────────► AIN1
PB13             ───────────► AIN2
PA1  (TIM2_CH2) ───────────► PWMB   右推进 PWM
PB14             ───────────► BIN1
PB15             ───────────► BIN2
PA4              ───────────► STBY
电池 A            ───────────► VM
稳定逻辑电源       ───────────► VCC
公共地             ───────────► GND
```

### 4.2 TB6612#2：滚筒与传送机构

```text
STM32                         TB6612#2
PB10 (TIM2_CH3) ───────────► PWMA   滚筒 PWM
PA11             ───────────► AIN1
PA12             ───────────► AIN2
PB11 (TIM2_CH4) ───────────► PWMB   传送机构 PWM
PB0              ───────────► BIN1
PB1              ───────────► BIN2
PA5              ───────────► STBY
电池 A            ───────────► VM
稳定逻辑电源       ───────────► VCC
公共地             ───────────► GND
```

上电和故障处理阶段应先让两颗 STBY 保持低电平；确认 GPIO 与 PWM 都进入安全状态后再使能驱动。

### 4.3 三路 AJ-SRP04M 超声波

```text
前：PA6  ─► Trig          PA7  ◄── Echo（经分压/电平转换）
左：PB5  ─► Trig          PB6  ◄── Echo（经分压/电平转换）
右：PB3  ─► Trig          PB4  ◄── Echo（经分压/电平转换，关闭 JTAG 后）
```

若 AJ-SRP04M 的 Echo 为 5 V，**PA7、PB4、PB6 均不得直接连接**。每一路都必须使用分压或双向/单向电平转换，使 MCU 引脚最高电平不超过 3.3 V。三个模块应共地，且由轮询触发以降低串扰。

### 4.4 MPU6050 与 QMC5883L 共用硬件 I2C1

```text
                         4.7 kΩ                 4.7 kΩ
3.3 V ───────────────────/\/\/── PB8 / I2C1_SCL ───┬── MPU6050 SCL
                                                     └── QMC5883L SCL
3.3 V ───────────────────/\/\/── PB9 / I2C1_SDA ───┬── MPU6050 SDA
                                                     └── QMC5883L SDA
GND ────────────────────────────────────────────────┼── MPU6050 GND
                                                     └── QMC5883L GND
```

- 两个模块的总线电平和上拉均接 3.3 V，推荐每线 4.7 kΩ。
- MPU6050 地址为 7 位 `0x68`（AD0 接 GND）；QMC5883L 地址为 7 位 `0x0D`，地址不同，可共线。
- 固件按硬件 I2C1、PB8/PB9 重映射和 100 kHz 总线配置。QMC5883L 当前提供原始三轴数据读取；用于航向前仍需完成安装后校准。

### 4.5 K230 与 GPS：独立硬件串口

```text
STM32 USART1（默认 115200 8N1）      K230
PA9  / TX  ───────────────────────►  RX
PA10 / RX  ◄───────────────────────  TX
GND        ───────────────────────── GND

STM32 USART2（默认 9600 8N1）       GPS
PA2  / TX  ───────────────────────►  RX
PA3  / RX  ◄───────────────────────  TX
GND        ───────────────────────── GND
```

两条链路均使用 3.3 V TTL 电平，TX/RX 必须交叉连接。K230 使用独立 USART1，GPS 使用独立 USART2；不要将 `printf` 或调试日志混入任一协议链路。

GPS 的接收缓冲、NMEA 帧接收与带校验和的有效 RMC 解析已完成源码接入，但尚未作为实机数据链路验证。请按 GPS 模块实际串口配置调整默认波特率。

### 4.6 SWD 下载与调试

```text
STM32              ST-Link
PA13 / SWDIO ────► SWDIO
PA14 / SWCLK ────► SWCLK
3.3 V        ────► VTref / 3.3 V
GND          ────► GND
```

保留 SWD 是本方案的硬性约束。PB3/PB4 的可用性依赖关闭 JTAG，而不是关闭 SWD。

## 5. 软件适配边界

- K230、GPS、硬件 I2C1、三路超声波和四路 TIM2 PWM 的引脚配置已按本表适配。
- GPS NMEA 与 QMC5883L 原始数据读取已经接入程序；它们仍需要现场通信、电平、安装方向和标定验证。
- RETURN 状态目前只做安全停车占位，不会以 GPS 与罗盘自动驱动返航。完成定位可靠性、航向校准、路径控制和故障策略验证前，不应将其用于自动返航。

## 6. 扩展接口与使用限制

| 引脚 | 建议用途 | 限制 |
| --- | --- | --- |
| PB7 | 水泵继电器、舱门限位、蜂鸣器 | 继电器/泵等负载必须经三极管或 MOSFET 驱动，并加合适的续流保护 |
| PA8 | TIM1_CH1 舵机 PWM、编码器输入 | 不能作为 ADC 使用 |
| PA15 | 普通 GPIO | 关闭 JTAG 后可用 |
| PC14 / PC15 | 低速 GPIO | 未使用外部 32.768 kHz 晶振时才可用 |

PB2 与启动配置有关，应保持下拉并避免作为扩展端口。任何新增外设都应先核对启动状态、电平兼容性、供电电流以及是否会与保留的 SWD/I2C/PWM 资源冲突。
