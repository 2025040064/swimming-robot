### 3.3 AJ-SRP04M ×3 — 超声波测距

```
STM32                        超声波模块
─────                        ─────────
PA6  GPIO ────────────────── Trig (前)
PA7  GPIO ────────────────── Echo (前)
    5V  ────────────────── VCC (前)
    GND ────────────────── GND (前)

PB5  GPIO ────────────────── Trig (左)
PB6  GPIO ────────────────── Echo (左)
    5V  ────────────────── VCC (左)
    GND ────────────────── GND (左)

PB7  GPIO ────────────────── Trig (右)
PB8  GPIO ────────────────── Echo (右)
    5V  ────────────────── VCC (右)
    GND ────────────────── GND (右)
```

> ⚠ **电平安全**：以上 3 个模块以 5V 供电，若其 Echo 输出为 5V 电平并直接接到
> STM32 GPIO（PA7/PB6/PB8 均为非 5V 容忍引脚），会超出 STM32 的绝对最大输入额定值。
> 请在每路 Echo 上加分压（如 1kΩ + 2kΩ）或电平转换到 3.3V 后再接 GPIO。

### 3.5 K230 — 视觉模块通信

```
STM32                        K230
─────                        ────
PA9  USART1_TX ───────────── RXD
PA10 USART1_RX ───────────── TXD
    GND        ───────────── GND

    波特率: 115200 / 8N1
```

> ⚠ 请确认 K230 与 STM32 的串口**同为 3.3V 逻辑电平**；若 K230 端为 5V 电平需加电平转换。
> 当前调试日志（DBG_PRINT）与 K230 视觉协议**共用 USART1**，调试输出会注入 K230 的
> RXD；量产时应将调试与视觉协议分到不同串口。

### 3.6 电池电压监测 — 已禁用（待重接线）

> ⚠ 原设计把分压中点接到 PA8 并标为 ADC12_IN8，这是**错误**的：PA8 在
> STM32F103C8T6 上**没有 ADC 功能**（ADC 通道 8 实际是 PB0，且 PB0 已被
> 传送电机方向脚 TB2_BIN1 占用）。因此「电池电压」实际读到的是电机控制电平。
>
> 当前固件已把电池 ADC **禁用**（BSP_ADC 各函数返回 0）。恢复时需按下方方案重接线。

若要恢复电池监测（二选一）：

1. 让位一个 ADC 引脚：把 TB1_STBY 从 PA4 挪到 PA8，电池分压中点改接 **PA4（ADC1_IN4）**。
2. 重新规划引脚，改用其它未被占用的 ADC 引脚（PA0–PA7 / PB0 / PB1）。

分压电路（R1=10kΩ 上臂、R2=4.7kΩ 下臂）公式不变：

```
电池正极  ────── R1=10kΩ ──────┬────── ADC引脚（如 PA4 = ADC1_IN4）
                               │
                             R2=4.7kΩ
                               │
电池负极  ─────────────────────┴────── GND

  V_adc = V_bat × 4700 / (10000 + 4700) = V_bat × 0.32
  V_bat = V_adc × (10000 + 4700) / 4700 = V_adc × 3.128

  2S LiPo 范围:  6.0V → ADC 1.92V → 2380 counts
                  8.4V → ADC 2.69V → 3331 counts
```
