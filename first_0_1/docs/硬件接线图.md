# D153C 扩展板接线

## 电机驱动模块 1：左右推进

```text
STM32                  D153C #1                    电机
PA0   ───────────────► PWMA ─ AIN1/AIN2 ──► AO1/AO2 左推进
PB12  ───────────────► AIN1
PB13  ───────────────► AIN2
PA4   ───────────────► STBY
PA1   ───────────────► PWMB ─ BIN1/BIN2 ──► BO1/BO2 右推进
PB14  ───────────────► BIN1
PB15  ───────────────► BIN2
GND   ───────────────► GND
```

## 电机驱动模块 2：回收机构

```text
STM32                  D153C #2                    电机
PB10  ───────────────► PWMA ─ AIN1/AIN2 ──► AO1/AO2 滚筒
PA11  ───────────────► AIN1
PA12  ───────────────► AIN2
PA5   ───────────────► STBY
PB11  ───────────────► PWMB ─ BIN1/BIN2 ──► BO1/BO2 传送机构
PB0   ───────────────► BIN1
PB1   ───────────────► BIN2
GND   ───────────────► GND
```

## 电源与未用接口

- 每块 D153C 的 `VM` 接对应电机电池正极。
- 电机电池负极、两块 D153C 的 GND、Blue Pill 的 GND 必须相连。
- `STBY` 由 MCU 控制，禁止直接常接 3.3 V。
- `ADC`、`E1A/E1B/E2A/E2B`、`Vout+` 暂不接入本项目；未确认 `Vout+` 电压和供电能力前，不要用它给 STM32 供电。
- 模块的 AO/BO 输出只接电机，不能接 STM32 或传感器。

## 其余接口

- K230：PA9(TX) 接 K230 RX；PA10(RX) 接 K230 TX；3.3 V TTL、共地。
- MPU6050：PB8=SCL、PB9=SDA、3.3V、GND；两条 I2C 线各 4.7 kΩ 上拉到 3.3 V。
- 超声波 Echo：PA7、PB6、PB4 前均需要 5 V→3.3 V 分压/电平转换。
