# 滤网模式与 MPU6050 倾角保护

当前正在按用户要求进行独立 MPU6050 电机台架测试，`ROBOT_IMU_MOTOR_TEST_ENABLE=1` 会绕过本说明中的正常导航和 `RANGE_HOLD` 路径；MPU6050 保护仍生效。最新测试固件和步骤见 [MPU6050 电机测试](MPU6050电机测试.md)。下文的 `RANGE_HOLD` 与早先构建记录适用于关闭该测试模式后的自动运行配置。

本页主体记录 2026-09-08 的滤网与倾角保护设计；当前扩展板引脚已按两块 TB6612、共享 I2C OLED 和 USART3 调试口重新分配，接线以《硬件接线图》为准。

## 当前可用范围

- 只有左右两个水平推进电机，没有垂直推进器或调平机构。因此本次实现倾斜限推力和超限停机，不具备主动调平能力。船体静态水平仍取决于浮力、配重和重心。
- MPU6050 的传感器 +X 朝上、+Y 朝船头。输入统一转换为 `(原Y, 原Z, 原X)`，加速度和角速度使用相同的右手坐标变换。发给 K230 的 STAT 字段仍为船身俯仰、横滚的顺序。
- 总倾角是加速度方向与船身“上”方向的夹角，覆盖向任意方向倾斜及翻覆。它受运动加速度影响，需在实船振动和波浪条件下验证。组合方向的倾斜也会触发保护，可能早于单独某一个轴达到阈值。
- 使用船底被动滤网，不再分配滚筒、传送机构电机。第二块 TB6612 改为 K230 云台的水平、俯仰直流电机；云台命令协议尚未定义，所以其 STBY 默认保持低电平。
- K230 继续发送 `TRASH,x,y\n`，坐标范围 0～639。目标横坐标决定左右差速，目标连续丢失超过 500ms 时立即将 PWM 清零。拒绝缺字段、越界、带尾部垃圾和超长的数据帧。
- 前超声波不足 50cm 一律进入避障，不再把不足 30cm 当作启动回收的条件。前左、前右探头各偏离正前方 60°，用于判断相应转向是否可行。侧方不足 60cm 或无有效测量时不向该侧转；没有可用方向时停机。
- 用户已确认摄像头能看到滤网入口，但目前没有垃圾进入滤网的确认信号，也没有入口图像坐标的标定。不会宣称“已收集成功”，不会在目标丢失后执行盲目前冲。

## 可见滤网入口的视觉控制边界

后续标定应使用 K230 发送目标坐标的同一幅图像：先确定入口的左右边界和入口边缘，再以入口中心作为接近目标的参考。当前 `IMG_CENTER_X=320` 只代表 640×640 图像中心，不代表实际滤网入口中心；若图像有裁剪、缩放或补边，必须先统一坐标系。

可以利用连续目标位置判断“接近入口”，并在入口前降低速度；只有实际看到目标从入口外跨过入口、且确认图像运动方向后，才可能建立“通过入口”的判据。单帧目标落在入口框内或目标消失，都不能单独证明垃圾已收集。具体方向、边界和时间阈值等待实际画面与 K230 程序，不预设为画面下方或固定 y 值。

结论是“本手册不能证明 AJ-SR04M 支持浸水测距”，而不是已完成水下失效实测。原 PDF 未修改。提取文本和页面证据保存在工作目录 `.embeddedskills/pdf_evidence/`，本次仅补充硬件证据与相机可见入口的确认，没有新增固件构建或实物测试结果。

## 保护参数与恢复

参数统一位于 `User/robot_config.h`：

- 上电约 3 秒静止校准；至少 200 个合格陀螺仪样本，校准时转动或明显加速会重置样本累计。未完成有效校准不得启动。
- 总倾角超过 12° 开始同比例降低左右推力，25° 时降低到 35%；这保持原左右指令比例，不产生调平力矩。
- 总倾角达到 25° 持续 200ms，进入 `TILT_STOP`。
- 总倾角达到 45°，在下一次有效的约 10ms 采样检查中立即停机，不等待 200ms。实际响应还包括传感器内部滤波与通信延迟。
- 100ms 没有可用 MPU6050 数据、全零/明显异常加速度持续 100ms，或上电 3500ms 后仍未完成有效姿态初始化，进入 `IMU_STOP`。
- `TILT_STOP` / `IMU_STOP` 清零 TIM2 四路 PWM 并关闭两块 TB6612。放平、恢复连接、后续 K230 数据均不能解除锁定；排除问题后重启。
- 保持 `tast_dianji.h` 的 `MOTOR_TEST_ENABLE=0`。独立电机测试路径会绕开正常任务和姿态保护。

MPU6050 的新加速度有效性检查按照当前 `AFS_SEL=3` 的 2048 LSB/g 计算，依据 [TDK/InvenSense 寄存器手册](https://invensense.tdk.com/wp-content/uploads/2015/02/MPU-6000-Register-Map1.pdf)。旧滤波代码中的 `±16g → 4096 LSB/g` 注释原文保留，其均匀缩放在角度比值中抵消；新增有效性检查不使用该旧比例。
