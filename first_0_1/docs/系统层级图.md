# 系统层级

```text
K230 ─ USART1 (PA9/PA10) ─┐
MPU6050 ─ I2C1 (PB8/PB9) ─┼─ STM32F103C8T6
三路超声 ─ GPIO/EXTI ────┤
                           ├─ TIM2 ─ D153C #1 ─ 左右推进
                           └─ TIM2 ─ D153C #2 ─ 滚筒、传送机构
```

- TIM2 的 CH1/CH2 位于 PA0/PA1，CH3/CH4 经部分重映射位于 PB10/PB11。
- 两块 D153C 的 A 路统一接 AO1/AO2，B 路统一接 BO1/BO2，便于排线和软件维护。
- 软件上电先使 STBY 低、电机 PWM 为零；完成 GPIO 和 PWM 初始化后再使能两块 D153C。
- 目前没有 GPS，因此导航与返航不驱动电机，只保持安全停车。
