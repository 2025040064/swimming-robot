# 水面垃圾清理机器人 — 系统层级图

> 更新日期：2026-09-02；适用主控：STM32F103C8T6 扩展版引脚方案；本文是设计与代码适配说明，不是硬件通电、通信或运动效果的实测报告。

---

## 一、设计目标与边界

- K230 与 GPS 使用彼此独立的硬件串口，避免视觉协议与 NMEA 数据互相干扰。
- MPU6050 与 QMC5883L 共用重映射后的硬件 I2C1 总线。
- TIM2 的四个通道保留为四路硬件 PWM，分别驱动左右推进、滚筒和传送机构。
- PA13/PA14 始终保留给 SWD；仅关闭 JTAG，以释放 PB3/PB4 供右侧超声波使用。
- 当前代码层已接入 GPS/NMEA 和 QMC5883L 原始数据读取；返航状态尚未执行闭环导航，进入后仍以安全停车作为占位行为。

## 四、AFIO 重映射与初始化顺序

所有重映射必须在相关 GPIO、TIM、I2C 或 EXTI 初始化之前执行。板级初始化的职责是一次性建立这一引脚契约：

```c
RCC_APB2PeriphClockCmd(RCC_APB2Periph_AFIO, ENABLE);

/* TIM2: CH1=PA0, CH2=PA1, CH3=PB10, CH4=PB11 */
GPIO_PinRemapConfig(GPIO_PartialRemap2_TIM2, ENABLE);

/* I2C1: SCL=PB8, SDA=PB9 */
GPIO_PinRemapConfig(GPIO_Remap_I2C1, ENABLE);

/* 关闭 JTAG，保留 PA13/PA14 的 SWD 调试 */
GPIO_PinRemapConfig(GPIO_Remap_SWJ_JTAGDisable, ENABLE);
```

```text
BSP_Board_Init()
    ├─ AFIO 时钟
    ├─ TIM2 PartialRemap2：PA0 / PA1 / PB10 / PB11
    ├─ I2C1 Remap：PB8 / PB9
    └─ JTAG Disable：释放 PB3 / PB4，同时保留 PA13 / PA14 的 SWD
             ↓
各外设初始化：LED、USART1、USART2、超声波、I2C1、MPU6050、QMC5883L、TIM2/TB6612
```

`GPIO_Remap_SWJ_JTAGDisable` 的含义是禁用 JTAG 而非禁用 SWD。因此 PB3/PB4 可分配给右侧超声波，ST-Link 仍应通过 PA13/PA14 下载和调试。不要改用 `GPIO_Remap_SWJ_Disable`，否则会同时丢失 SWD。

### 周期任务关系

| 周期 | 当前任务 | 与扩展版引脚方案的关系 |
|---:|---|---|
| 10 ms | 读取 K230、读取 GPS 字节、读取 MPU6050、更新姿态 | USART1、USART2 和 I2C1 同时服务，但通道独立 |
| 20 ms | 状态机运行 | 使用目标、姿态和超声安全信息 |
| 50 ms | 读取 QMC5883L 原始三轴数据 | 使用与 MPU6050 共线的 I2C1 |
| 100 ms | LED 心跳 | PC13 |
| 200 ms | 发送状态遥测 | 经 K230 专用 USART1 链路 |
| 1000 ms | K230/GPS 串口溢出与丢包监控 | 分别监视两路 UART |

### 导航功能边界

```text
GPS 字节流 → NMEA 行 → 校验和通过的有效 RMC → 当前坐标更新
QMC5883L   → I2C1 原始 X/Y/Z 磁场数据 → 等待安装方向与硬/软铁校准
                                      ↓
STATE_RETURN → App_Ctrl_ReturnBase() → DRV_TB6612_StopAll()
```

因此，GPS/NMEA 解析和 QMC5883L 原始读取已经在代码层适配到新总线/串口分配；它们尚未构成可宣称完成的返航闭环。返航状态目前故意安全停车，待补齐航向标定、原点策略、定位有效性与导航控制后再启用运动。

## 六、接线与电气约束

### 超声波 Echo 电平

AJ-SRP04M 的 Echo 若输出 5 V，PA7、PB4、PB6 都不能直接承受该电平。每一路 Echo 必须先经过分压或 3.3 V 兼容的电平转换，再连接 STM32：

```text
AJ-SRP04M Echo (可能为 5 V) ─► 分压 / 电平转换 ─► STM32 Echo 输入
                                            ├─ PA7：前方
                                            ├─ PB4：右侧
                                            └─ PB6：左侧
```

Trig 为 STM32 的 3.3 V 输出；实际模块是否能可靠识别 3.3 V 高电平，需要以所用 AJ-SRP04M 的规格和实物测试确认。

### I2C 与 UART

- MPU6050 和 QMC5883L 的 I2C 上拉应接 **3.3 V**，推荐每条总线使用约 **4.7 kΩ** 上拉电阻；两模块使用 7 位地址 `0x68` 与 `0x0D`，可以共线。
- K230、GPS 与 STM32 的 UART 均使用 **3.3 V TTL** 电平，TX/RX 必须交叉连接：STM32 TX 接外设 RX，STM32 RX 接外设 TX。
- 两路 UART 在软件和接线上保持独立：USART1 仅用于 K230，USART2 仅用于 GPS；不要将调试日志混入任一路协议链路。

### 电机与供电

- TB6612 的 VM 接电池 A；逻辑供电采用稳定的 3.3 V/5 V 转换电源。
- 电机电源、驱动逻辑电源、STM32、K230、GPS 和传感器必须共地。
- 四路 PWM 仅定义了 MCU 侧资源和软件控制关系；电机转向、负载能力、供电压降与 EMC 表现仍需在实际接线后验证。
