# 系统层级

```text
K230 ─ USART1 (PA9/PA10) ──────┐
调试口 ─ USART3 (PB10/PB11) ──┤
MPU6050 + OLED ─ I2C1 (PB8/PB9) ─┼─ STM32F103C8T6
三路超声 ─ GPIO/EXTI ─────────┤
                                ├─ TIM2 CH1/CH2 ─ TB6612 #1 ─ 左右推进
                                └─ TIM2 CH3/CH4 ─ TB6612 #2 ─ 云台水平、俯仰
```

- TIM2 使用默认映射：CH1/CH2 位于 PA0/PA1，CH3/CH4 位于 PA2/PA3。
- 两块 TB6612 的 A 路统一接 AO1/AO2，B 路统一接 BO1/BO2，便于排线和软件维护。
- 软件上电先使 STBY 低、电机 PWM 为零；推进桥由现有安全状态机使能，云台桥在云台协议完成前默认保持待机。
- 目前没有 GPS，因此导航与返航不驱动电机，只保持安全停车。
