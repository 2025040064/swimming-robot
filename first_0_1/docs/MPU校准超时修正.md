# MPU 校准超时修正（2026-09-11）

最新实机证据：ImuStopReason=2，StopCalibCount=0x13（19），CalibRejectMask=3，ImuReadFailures=0，加速度模长平方拒绝值为 1.21057582，陀螺仪原始绝对值拒绝值为 179。本次停机原因是启动校准未完成，并非通信读失败。诊断值来自最近一次对应的拒绝记录，不能证明整段采样始终稳定。

原校准要求加速度模长为 0.9～1.1g，陀螺仪绝对原始值不超过 164，越界会清空连续计数。原状态机又在 3 秒时无条件结束采集，即使不足 200 个样本，也无法利用剩余 0.5 秒继续采集。

本次修改：

- 幅度容差改为 0.85～1.15g，陀螺仪绝对原始值不超过 280，允许本板观测到的稳定偏差进入校准。
- 新增整个连续采样窗口各轴峰峰值限制：加速度 256 LSB、陀螺仪 164 LSB，越界清空计数，RejectMask 的位 3 记录窗口不稳定。
- 达到 3 秒且连续样本至少 200 个才结束校准；不足时继续采集，仍受原 3.5 秒上限约束。
- 保留有效采样超时 100ms、25°持续200ms停机、45°立即停机、故障锁定到复位、30秒测试结束以及 PWM=3600。

稳定偏置可以通过平均值校准，波动和累计漂移由窗口限制拒绝。惯性数据不能完全区分恒定慢速旋转与陀螺仪偏置，启动期间仍须实际保持静止。新参数是针对本板观测的台架配置，其实机效果仍待确认。

新增测试覆盖稳定 1.10g/179 及原始陀螺仪 257 的样本、陀螺仪和加速度往复波动、缓慢漂移、3秒计数不足但3.5秒前完成窗口、超范围加速度。三个应用配置回归测试通过；Keil Target 1 编译 0 错误、0 警告。没有自动下载，尚未验证实机电机转动。
