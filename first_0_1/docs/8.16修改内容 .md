## 1. 图像中心基准修正 0 → 320

**文件**: `User/app/app_control.h:7-9`

```c
// 旧: 中心基准是左上角 (0,0)，PID 会把目标往左上角推
#define IMG_CENTER_X    0
#define IMG_CENTER_Y    0

// 新: K230 下发坐标在 640×640 坐标系内，画面中心 = (320,320)
#define IMG_CENTER_X    320
#define IMG_CENTER_Y    320
```

**依据**: K230 输入/输出均为 640×640（用户确认），`pkt->x/y` 是像素坐标（±5px 噪声），故中心 = 分辨率一半。

**影响**: 修复前 PID 设定点 (0,0) 位于画面左上角，机器人会把目标"追"向左上角而非画面中央，无法正确对准。

## 2. X 轴（偏航）转向方向修正 —— 原来方向反了 🔴

**文件**: `User/app/app_control.c`

PID 内部约定 `error = setpoint − input = 320 − targetX`，kp > 0。

**旧代码**:
```c
left  = APPROACH_SPEED + (int16_t)pidX - (int16_t)pidY;
right = APPROACH_SPEED - (int16_t)pidX + (int16_t)pidY;
```

**错误推导**（目标在画面左侧，targetX=100 < 320）:
```
errorX = 320 − 100 = +220  →  pidX > 0
left  = 3000 + pidX  →  左轮加速
right = 3000 − pidX  →  右轮减速
→ 左快右慢 = 顺时针【右转】，但目标在左，应左转 → 背离目标，永远不收敛
```

**新代码**（翻转 pidX 符号）:
```c
left  = APPROACH_SPEED - (int16_t)pidX;
right = APPROACH_SPEED + (int16_t)pidX;
```

目标在左 → 左慢右快 → **左转**，对准目标 ✅

## 3. 移除 Y 轴差速转向 —— yaw-only 控制

**文件**: `User/app/app_control.c`

**问题**: 原代码把画面垂直偏移 `pidY` 混入左右差速，即"目标上下浮动会让船转向"。但这是一条**水面差速船**，只有左右推进器 + 收集滚轮，没有俯仰执行器。画面里的上下位置主要由距离和船身随波浪摇晃决定，是噪声而非转向信号，会导致目标稍偏上/偏下就乱扭。

**改动**:
- 删除 `g_pidY` 对象、`pidY`/`errorY` 局部变量及其 Init/Reset
- 电机分配只由 `pidX` 驱动
- `g_targetY` 保留接收 `pkt->y`（留作未来距离控制），接口 `App_Ctrl_SetTarget(x,y)` 签名不变

## 5. PID 调参: kp_x 18 → 10

**文件**: `User/app/app_control.c`

```c
// 旧: kp=18 → 最大 P = 18*320 = 5760 > 4000 钳位
//     在 |误差| > 222px 时即饱和 → 满速/停止两档 (bang-bang)
Algo_PID_Init(&g_pidX, 18.0f, 0.2f, 2.0f, 4000.0f, -4000.0f, 4000.0f);

// 新: kp=10 → 最大 P = 10*320 = 3200 < 4000 钳位，全程比例输出
Algo_PID_Init(&g_pidX, 10.0f, 0.2f, 2.0f, 4000.0f, -4000.0f, 4000.0f);
```

改后转向行为（APPROACH_SPEED=3000）:

| 目标偏移 | pidX | 左轮 | 右轮 | 效果 |
|---|---|---|---|---|
| 20px（死区外） | 200 | 2800 | 3200 | 轻微修正 |
| 50px | 500 | 2500 | 3500 | 温和转弯 |
| 100px | 1000 | 2000 | 4000 | 明显转弯 |
| 200px | 2000 | 1000 | 5000 | 急转 |
| 320px（最边缘） | 3200 | −200 | 6200 | 原地掉头 |

## 验收要点（台架验证，必做）

代码逻辑已修正，但"左/右"对应哪个物理电机、正 PWM 是否前进取决于接线，需台架确认：

1. 船架空（桨离水 / 轮离地）
2. 发假目标 `x=100, y=320`（目标在画面左侧）
3. 船应**向左偏航**
   - 左转 ✅ → 通过
   - 反而右转 → 硬件存在一次反向（左右电机线对调 或 TB6612 正负接反），二选一：回退本次 X 轴翻转，或对调左右电机线
