# MPU6050 对推进电机输出的独立测试

本测试使用实际项目的 MPU6050 读取、安装方向转换、校准、倾角保护和 PWM 输出路径。K230 目标及超声波测量不会影响测试转速，回收机构保持禁用。测试改变的是 PWM 占空比，未安装转速反馈，不能将占空比百分数当作实际 RPM 百分数。

## 当前开关

在 `User/bsp/test/bsp_mpu_motor_test.h`：

```c
#define ROBOT_IMU_MOTOR_TEST_ENABLE  1
#define ROBOT_IMU_TEST_PWM          2000
#define ROBOT_IMU_TEST_DURATION_MS  30000U
```

测试运行逻辑、30 秒计时、结束锁定和 `MPUTEST` 输出位于同目录的 `bsp_mpu_motor_test.c`；Keil 中放在现有 `BSP` 分组的末尾，紧接 `bsp_debug.h`。磁盘目录仍为 `User/bsp/test/`。`robot_config.h` 引用该头文件，原有应用层只保留测试调度及公共保护/PWM 接口。

`tast_dianji.h` 原来的 `MOTOR_TEST_ENABLE` 保持 0，它是另一条固定转速测试路径，不会读取 MPU6050。两种测试同时打开时会报编译错误。

## 上板测试步骤

1. 固定船身和电机，确保桨叶附近无人接触。保持 MPU6050 **+X 向上、+Y 朝船头**。若只想先测电气输出，可以断开电机电源，用示波器观察 PA0/PA1；电机上电测试需满足电机本身的运行条件。
2. 下载本次 `Objects/first_0_1.hex`。正常供电、共地；K230 和三个超声波无需连接。上电/复位后静止约 3 秒校准，随后左右电机在约 200ms 内缓慢升到 PWM 2000（约 27.8% 占空比）。
3. 缓慢倾斜整个传感器/船身，保持姿态稳定再观察。0～12°：PWM 约 2000；20°：约 1200；24°：约 800。左右输出同步变化，放平后恢复基准值。不要用剧烈摇晃代替静态倾角测试。
4. 达到 25° 并持续约 200ms：全部 PWM 清零，进入 `TILT_STOP`；约 45°以上在下一次有效采样检查中直接触发停机。实际响应还包括芯片滤波延迟。放平不会恢复，排除问题后重启再测。
5. 在供电稳定的前提下中断 MPU6050 通信，连续约 100ms 无可用数据后应进入 `IMU_STOP`，左右输出清零且推进桥关闭。恢复连接也不会自动启动。
6. 正常测试从首次起转开始计时，30 秒到期进入 `TEST_DONE`，两块驱动 STBY 均关闭；保持停机，重启才能再测。

两个水平推进电机不会主动纠正船身俯仰/横滚。本测试验证的是“倾角越大，限推力越强”和停机保护。

## 可观察数据

USART1 的 PA9 输出、115200、8N1，使用原有 K230 通信口。若接 USB 串口观察，将 PA9 接串口 RX 并共地，使用 3.3V TTL；不要把另一个发送端并到已经由 K230 驱动的 PA10 上。

每 200ms 发送原有 `STAT,...` 状态，并追加：

```text
MPUTEST,20.0,1200,1200
```

三个字段依次是总倾角（度）、左 PWM、右 PWM。数值是输出命令，不是编码器测得的转速。可在 Keil Watch 中查看 `g_outputLeft`、`g_outputRight`、`g_thrustScale` 和状态变量。

若 PWM 随倾角改变，但电机在较小 PWM 下不转，需检查低占空比的启动力矩、电源和负载；这与 MPU6050 完全没有输出是不同的问题。若显示 `IMU_INIT_FAILED`，先检查 MPU6050 供电、PB8/PB9 接线和上拉；若显示 `IMU_STOP`，检查静止校准和通信。

## 恢复正常配置

将 `ROBOT_IMU_MOTOR_TEST_ENABLE` 改为 0 后重新编译、下载。不要为结束测试去修改 `ROBOT_RANGING_VALIDATED`；它仍为 0，正常模式的浸水测距问题尚待解决。
